# 📝 GPT Prompt Templates - Copy & Paste Vào ChatGPT

Dùng file này để lấy prompt cho từng kênh. Copy prompt → paste vào ChatGPT →
lấy kịch bản → paste vào VietCreator Studio → nhấn tạo video.

---

## 🌌 Kênh 1: Space & Universe (Tiếng Anh)

```
Write a 30-60 second video script about: [TOPIC HERE]

Rules:
- Start with a shocking hook question or statement
- Present 3-4 mind-blowing space facts
- Use vivid, cinematic descriptions
- Short punchy sentences, easy to understand
- End with a thought-provoking statement
- Write 3-4 paragraphs, each paragraph = 1 visual scene
- Do NOT use any titles, greetings, or markdown
- Just raw narration text, nothing else

Example topic: "What if the Sun disappeared right now?"
```

---

## 🧘 Kênh 2: Stoic Wisdom (Tiếng Anh)

```
Write a 20-45 second Stoic philosophy video script about: [TOPIC OR QUOTE HERE]

Rules:
- Open with the full quote and its author
- Explain what it means in simple modern language
- Give ONE practical lesson viewers can apply today
- Use a calm, wise, authoritative tone
- Write 2-3 paragraphs
- Do NOT use titles, greetings, bullet points, or markdown
- Just raw narration text

Example topic: "We suffer more in imagination than in reality - Seneca"
```

---

## 😱 Kênh 3: Dark Facts (Tiếng Anh)

```
Write a 30-60 second creepy/disturbing facts video script about: [TOPIC HERE]

Rules:
- Start with the MOST disturbing fact to hook viewers
- Present 3-5 unsettling but TRUE facts
- Use suspenseful, eerie pacing
- Short sentences that build tension
- End with a chilling question or the scariest fact
- Write 3-4 paragraphs
- Do NOT use titles, greetings, or markdown
- Just raw narration text, factual but terrifying

Example topic: "Things your body does after you die"
```

## 👻 Kênh 4: Truyện Ma (Tiếng Việt)

```
Viết kịch bản truyện ma cho video ngắn 45-90 giây về: [CHỦ ĐỀ Ở ĐÂY]

Quy tắc:
- Mở đầu bằng câu hook rùng rợn, gây tò mò ngay giây đầu
- Kể theo ngôi thứ nhất "Tôi" để tạo cảm giác chân thực
- Mô tả chi tiết không khí: âm thanh, bóng tối, cảm giác lạnh gáy
- Tạo cao trào ở giữa và twist bất ngờ ở cuối
- Viết 4-5 đoạn ngắn, mỗi đoạn = 1 cảnh hình ảnh
- KHÔNG dùng tiêu đề, lời chào, markdown
- Chỉ viết nội dung kể chuyện thuần túy

Ví dụ chủ đề: "Tiếng gõ cửa lúc 3 giờ sáng"
```

## 🔍 Kênh 5: Bí Ẩn Thế Giới (Tiếng Việt)

```
Viết kịch bản video ngắn 30-60 giây về bí ẩn: [CHỦ ĐỀ Ở ĐÂY]

Quy tắc:
- Mở đầu bằng sự thật gây sốc hoặc câu hỏi kích thích tò mò
- Trình bày 3-4 sự thật bí ẩn liên quan
- Giọng văn truyền cảm, hấp dẫn, dễ hiểu
- Xen kẽ thông tin khoa học và yếu tố bí ẩn chưa giải đáp
- Kết thúc bằng câu hỏi mở hoặc sự thật bất ngờ nhất
- Viết 3-4 đoạn ngắn
- KHÔNG dùng tiêu đề, lời chào, markdown
- Chỉ viết nội dung thuần túy

Ví dụ chủ đề: "Tam giác quỷ Bermuda"
```

## 💡 Mẹo Dùng GPT Hiệu Quả

1. **Batch**: Yêu cầu GPT viết 5-10 kịch bản cùng lúc
   ```
   Write 5 separate scripts about these topics:
   1. What happens if the Moon disappeared
   2. The coldest place in the universe
   3. Why Mars is red
   4. How big is the Milky Way
   5. What is a neutron star
   
   [paste rules from above]
   Separate each script with "---"
   ```

2. **Chỉnh giọng**: Thêm "Use a [mysterious/energetic/calm] tone"

3. **Độ dài**: Thêm "Keep it under 100 words" cho Shorts ngắn
